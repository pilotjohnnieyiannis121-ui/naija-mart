
# Naija Mart 🇳🇬

**Discover products. Connect with sellers. Shop across Nigeria.**

Naija Mart is a mobile-friendly Nigerian marketplace project designed to help buyers discover products and connect with sellers across Nigeria.

## Features

- Browse sample products and prices.
- Search by product, category, and location.
- Explore products from different Nigerian locations.
- Choose between buyer and seller account options.
- Preview a seller application and approval workflow.
- Responsive design for mobile phones and computers.
- Green, white, and gold visual theme.

## Technologies

- HTML
- CSS
- JavaScript

## Project Files

- `index.html` — Website structure.
- `styles.css` — Website appearance and responsive layout.
- `app.js` — Search, navigation, and preview interactions.
- `README.md` — Project information and setup instructions.
- `.gitignore` — Files Git should ignore.

## How to Run

1. Keep `index.html`, `styles.css`, and `app.js` in the same folder.
2. Open `index.html` in a web browser.
3. Test the search, category filters, navigation, and account preview.

## Important Note

This is an early website preview. Real user accounts, Firebase integration, live product storage, seller approval, messaging, payments, and the admin dashboard still need to be implemented and tested.

Never publish passwords, private keys, or Firebase Admin credentials in this repository.
